# 🌐 LinguaBridge — Modern Web Translator

A lightweight, fast, and responsive web-based translation application built with vanilla JavaScript, HTML5, and CSS3. **LinguaBridge** offers seamless text translation across 15 popular languages, integrated text-to-speech functionality, and direct clipboard support.

🚀 **Live Demo:** [https://fizzahashmi45.github.io/translater/](https://fizzahashmi45.github.io/translater/)

---

## ✨ Features

- **Instant Text Translation:** Translate text across 15+ major global languages using the free MyMemory Translation API.
- **Text-to-Speech (TTS):** Integrated Web Speech API to listen to both source input and translated output pronunciations.
- **One-Click Language Swap:** Quickly toggle source and target languages with a single click.
- **Copy to Clipboard:** Copy translations instantly to your clipboard.
- **Character Count Limit:** Real-time character monitoring (up to 500 characters per request).
- **Fully Responsive UI:** Dark-themed, modern interface optimized for desktop, tablet, and mobile views.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3 (CSS Variables & Grid/Flexbox), JavaScript (ES6+)
- **API:** [MyMemory Translation API](https://mymemory.translated.net/)
- **Browser APIs:** Web Speech API (`SpeechSynthesis`), Clipboard API

---

## 🌐 Supported Languages

English, Spanish, French, German, Italian, Portuguese, Russian, Chinese (Simplified), Japanese, Korean, Arabic, Hindi, Urdu, Turkish, Dutch.
